리바트 키즈 벙커침대는 부품 수가 많고 조립 순서가 정해져 있습니다

리바트 키즈 벙커침대와 이층침대는 상판 프레임, 계단·사다리, 안전가드, 책장과 서랍장이 서로 맞물려 하나의 구조를 이룹니다. 해체할 때 어떤 부품이 어디에 들어갔는지 구분해 두지 않으면, 새 집에서 다시 맞출 때 나사 구멍이 어긋나거나 프레임이 흔들리기 쉽습니다.

코니처 기사는 리바트에서 10년간 일하며 리바트 가구를 직접 다뤄 왔습니다. 제품마다 다른 부품 구성과 조립 순서, 오래 쓴 침대에서 헐거워지기 쉬운 곳을 알고 있어서, 설명서가 없어도 구조를 빠르게 파악합니다.

기존 위치에서 침대를 분리·해체하면서 부품과 나사를 구분해 정리하고, 운반 후 새 방의 벽 위치·창문·문 열림 방향을 보고 배치를 잡은 뒤 재설치합니다. 마지막에는 아이가 오르내리는 계단과 위층 가드가 단단히 고정됐는지 직접 흔들어 확인합니다.

중고로 구입하셨다면 더 중요합니다

판매자 집에서 해체부터 해야 하는지, 이미 분해된 부품을 받아 조립만 하면 되는지에 따라 작업이 달라집니다. 설명서가 없어도 침대 사진을 보면 구조를 확인할 수 있으니, 거래 전에 먼저 상담해 주세요.
